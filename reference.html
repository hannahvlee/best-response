04 오답 함정 — 소문자 a~f
a
WH 정보 혼동 ★★★
When→Where, Where→Who 등 질문이 요구하는 정보 유형을 바꿔치기
b
키워드·연상 함정 ★★★★
질문의 핵심 단어를 그대로 쓰거나 연상 단어를 삽입해 관련 있어 보이게 만듦
c
주어·역할 혼동 ★★★
요청자↔수행자 역할이 뒤바뀐 선택지
d
시제·상황 어긋남 ★★★
과거 질문에 미래형으로 답하거나 이미 끝난 일을 앞으로 할 일처럼 답함
e
주제 연관 오답 ★★★★
주제·상황과 관련은 있지만 질문의 핵심을 비껴가는 선택지
f
완전 무관 함정 ★

06 유형별 주의사항
1 정보 요청형
직접 답변이 정답인 경우는 생각보다 적음. 간접·우회 답변이 약 30%. "모른다"는 답도 충분히 정답이 될 수 있음.
2 제안·요청·초대형
Yes/No 대신 조건부·역질문이 정답인 경우 많음. "No"를 직접 말하지 않는 간접 거절 표현에 익숙해야 함.
3 의견·선호형
A or B 중 하나를 고르라는 질문에 "둘 다" 또는 "둘 다 아님"이 정답인 경우가 자주 나옴. 일상 대화 흐름을 따라갈 것.
4 경험·근황형
Did you...? 질문에 Yes/No로 시작하는 선택지가 오히려 오답인 경우 많음. 이유·상황 설명이 정답인 경우가 절반 이상.
5 일정·상황 공지형
공지 내용과 완전히 무관한 선택지를 먼저 제거하면 빠르게 좁힐 수 있음. 공지에 이미 포함된 정보를 다시 말하는 선택지는 오답.
6 감상·공감 반응형
단순 공감("That's too bad.")보다 실용적 해결책 제안이 정답인 경우가 더 많음. 감정만 담은 선택지는 오답일 가능성이 높음.
07 오답 풀이 순서
1.
f 완전 무관 선택지 먼저 제거 → 선택지를 2~3개로 좁히기
2.
a WH 정보 유형 확인 → 질문의 WH 단어에 맞는 정보 유형만 남기기
3.
d 시제 확인 → 질문 시제와 맞지 않는 선택지 제거
4.
c 주어·역할 방향 확인 → 역할이 뒤바뀐 선택지 제거
5.
b e 남은 선택지에서 키워드 함정·부분 정보 함정 주의
